# Armada Docs

Documentation for [Armada](https://armada.buzz) — how it works, and how to
self-host it. A static [Astro](https://astro.build) +
[Starlight](https://starlight.astro.build) site: every page is HTML on disk at
build time, with no server and no client-side routing.

## Commands

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # -> dist/
npm run preview  # serve dist/ exactly as it will be deployed
```

`npm run build` is the check: Astro validates the content collection against its
schema, so bad frontmatter fails the build rather than shipping.

## Layout

| Path | What |
|------|------|
| `src/consts.ts` | The deployed origin, the site copy, and every off-site link. Change a URL here, not in a page. |
| `src/pages/index.astro` | The homepage. Not a Starlight page — its own layout and full-bleed hero. |
| `src/pages/robots.txt.ts` | Generated from `SITE_URL`, so the sitemap line can't point at the wrong host. |
| `src/layouts/Landing.astro` | The shell for non-docs pages: head, SEO tags, top bar, footer. |
| `src/content/docs/` | The documentation itself. A new file appears in the sidebar by existing. |
| `src/styles/theme.css` | Armada's design tokens, lifted from the app. |
| `src/styles/starlight.css` | Those tokens mapped onto Starlight's `--sl-*` variables. |
| `src/components/` | Brand surfaces ported from the app: the crest, the wordmark, the ASCII sea. |

## Writing docs

Add a Markdown file under `src/content/docs/how-it-works/` or
`src/content/docs/self-hosting/`. The sidebar is autogenerated from those two
directories, so nothing else needs editing; set `sidebar.order` in the
frontmatter to place it.

Every page needs a `description` — it becomes the meta description and the
social card text, and without one the page competes for search results with a
snippet the crawler picked itself.

## Deploying

`dist/` is a plain static directory. Two things the host must get right:

- **`SITE_URL` in `src/consts.ts` must be the real origin.** It feeds canonical
  links, `sitemap-index.xml` and the absolute `og:image` URLs. A wrong value
  does not fail the build — it silently ships a sitemap for a host that isn't
  serving the site.
- **Build from full git history.** `lastUpdated` reads the git log, so a shallow
  CI clone (`fetch-depth: 1`) makes every page claim the same date.

URLs are directory-style with a trailing slash (`/self-hosting/relay/`). Serve
`404.html` for misses and don't rewrite unknown paths to `index.html` — a static
site has no router to recover them.
